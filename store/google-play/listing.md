## 2. 스토어 등록정보

### 앱 이름 (최대 30자)
```
로또 틈새번호 - 당첨확인·번호생성
```
"로또"를 제목 앞에 둬서 검색에 잡히게 했어요. 공식 앱으로 오해받지 않도록 자세한 설명의 "동행복권 및 복권위원회와 관련 없음" 문구는 꼭 유지하세요.

### 간단한 설명 (최대 80자)
```
당첨 확률은 같아요. 1등이 되면 덜 나누는 번호와 세후 예상 수령액, QR 당첨 확인까지.
```

### 자세한 설명 (최대 4,000자)
```
로또는 어떤 번호든 당첨 확률이 똑같아요. 814만 5,060분의 1이죠.
그런데 1등이 되면 받는 돈은 달라요. 같은 번호를 산 사람이 많을수록 상금을 여러 명이 나눠 갖거든요.

틈새번호는 번호를 "맞혀 주는" 앱이 아니에요.
1등이 되었을 때 상금을 덜 나누도록, 사람들이 잘 고르지 않는 번호를 골라 드려요.

■ 상금 지키는 번호
역대 1,200회가 넘는 당첨자 수를 분석해 번호별 인기도를 추정했어요.
생일처럼 31 이하에 몰린 번호, 연속 번호, 용지의 한 줄처럼 사람들이 일부러 고르는 모양은 피하고,
덜 겹치는 조합만 뽑아요. 세트마다 1등일 때의 세후 예상 수령액도 함께 보여 드려요.

■ 내 번호 진단
늘 사는 번호가 있다면 넣어 보세요.
얼마나 많은 사람이 고르는 조합인지, 1등이 되면 평균 몇 명과 나누게 될지,
세금을 떼고 얼마를 받을지 계산하고, 덜 겹치는 대안 번호도 추천해요.

■ QR 당첨 확인
복권 용지의 QR 코드를 비추면 회차와 모든 게임을 읽어 등수와 당첨금을 바로 보여 줘요.
확인한 번호는 한 번에 저장할 수 있어요.

■ 내 번호
산 번호를 회차별로 저장해 두면, 추첨이 끝난 뒤 앱을 열 때 자동으로 맞춰 보고 결과와 누적 당첨금을 보여 줘요.
저장한 번호는 이 기기에만 남아요.

■ 그때부터 샀다면 (시뮬레이션)
이 번호로 1년, 5년, 20년 전부터 매주 샀다면 얼마를 쓰고 얼마를 받았을지,
실제 역대 당첨 결과로 계산해요. 가장 아까웠던 회차도 알려 드려요.

■ 기록
• 회차별 당첨번호와 등수별 당첨금, 번호로 회차 찾기
• 1·2등 당첨 판매점과 지역별 순위, 네이버 지도로 위치 보기
• 번호별 출현 횟수, 홀짝·고저·합계·끝수 분포를 무작위일 때의 이론값과 나란히
• 1등 자동·수동 비율과 역대 기록

■ 그 밖의 뽑기 방법
완전 무작위, 당첨번호 닮은꼴, 많이 나온 번호, 오래 안 나온 번호, 내 후보 번호로 조합, 문구로 뽑기.
고정수·제외수, 홀짝·합계 조건도 넣을 수 있어요.

■ 알아 두세요
• 어떤 방법을 써도 당첨 확률은 높아지지 않아요. 틈새번호는 당첨을 예측하거나 보장하지 않아요.
• 예상 수령액은 최근 회차의 판매량과 1등 총액으로 계산한 추정치예요. 실제 금액은 회차마다 달라요.
• 당첨금을 받을 때는 반드시 실물 복권으로 확인하세요.
• 로또 복권은 만 19세 이상만 구매할 수 있어요.
• 틈새번호는 동행복권 및 복권위원회와 관련이 없는 정보 서비스이며, 복권을 판매하지 않아요.
• 회원가입이 없어요. 저장한 번호는 이 기기에만 남아요.
```

## 6. 나중에 AdMob 광고를 붙일 때 바꿀 것

광고를 넣은 버전을 올리기 **전에** 아래를 함께 바꿔야 해요. 정책 설문과 실제 앱이 다르면 앱이 거부되거나 삭제될 수 있어요.

| 어디 | 지금 (광고 없음) | 광고를 붙이면 |
|---|---|---|
| Play Console > 앱 콘텐츠 > 광고 | 광고 없음 | **광고 포함**. 스토어에 "광고 포함" 표시가 붙어요 |
| 데이터 보안 | 수집·공유 없음 | AdMob SDK가 수집하는 항목을 신고: 기기 또는 기타 ID(광고 ID), 앱 상호작용, 진단 정보, 대략적인 위치 등. Google의 [AdMob 데이터 보안 안내](https://developers.google.com/admob/android/privacy/play-data-disclosure)대로 "광고 또는 마케팅" 목적으로 공유 |
| 개인정보처리방침 | 광고·분석 도구 없음 | 광고 업체(Google AdMob), 수집 항목, 광고 ID 사용, 맞춤 광고 끄는 방법(기기 설정 > Google > 광고)을 추가 |
| Android 권한 | — | `com.google.android.gms.permission.AD_ID` (Android 13 이상에서 광고 ID 사용에 필요) |
| 동의 화면 | — | 유럽(EEA)·영국 사용자를 받으려면 Google UMP 동의 메시지. 국내만이면 필수는 아니지만 AdMob 콘솔에서 확인 |

구현 메모:
- Expo에서는 `react-native-google-mobile-ads`(커뮤니티 라이브러리, config plugin 제공)를 쓰고, 네이티브 모듈이라 **새 빌드**가 필요해요. EAS Update(무선 업데이트)로는 못 넣어요.
- 로또 관련 앱이라 AdMob의 [게시자 정책](https://support.google.com/admob/answer/6128543) 중 도박 관련 항목을 확인하세요. 이 앱은 베팅·복권 판매가 없는 정보 앱이지만, 광고 노출이 제한될 수 있어요.
- 앱의 "정직한 앱" 포지셔닝을 지키려면, 결과 화면이나 번호 목록 사이처럼 오해를 부를 위치(당첨처럼 보이는 배너 등)는 피하는 게 좋아요.
